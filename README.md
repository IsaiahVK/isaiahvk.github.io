# Isaiah Kushner — Personal Portfolio

Welcome to the repository for my personal portfolio website, hosted directly via **GitHub Pages** at:
👉 **[https://isaiahvk.github.io/](https://isaiahvk.github.io/)**

---

## 🌟 Features

- **Responsive & Modern Design:** Optimized for mobile phones, tablets, and desktop displays.
- **Dark / Light Mode:** Built-in theme switcher with smooth transitions and persistent user preference in `localStorage`.
- **Zero Build Step:** Built with pure semantic HTML5, CSS3 variables, and vanilla JavaScript—no npm, bundlers, or heavy frameworks required. Fast and instant deployment.
- **Accessible & Clean:** High-contrast typography, interactive hover states, accessible navigation, and scroll spy.
- **Sections Included:**
  - **Hero:** Personal intro, availability status pill, resume link, call-to-action buttons, and social profiles.
  - **About:** Background narrative and highlight summary cards.
  - **Education:** Degree cards with 4.0 GPA badges, honors, and coursework.
  - **Experience:** Journey timeline with roles, accomplishments, and tech tags.
  - **Projects:** Showcase cards featuring technology tags and GitHub repository links.
  - **Contact:** Direct interactive contact tiles (Email, Phone, LinkedIn, GitHub, Locations).

---

## 📁 Project Structure

```text
isaiahvk.github.io/
├── index.html        # Main HTML structure and content
├── css/
│   └── style.css     # Design tokens, themes, layout, and responsive styles
├── js/
│   └── main.js       # Theme toggle, mobile menu, scroll spy, and interaction
├── assets/           # Placeholders for images, icons, and documents (resume)
└── README.md         # Documentation & guide
```

---

## 🚀 How to Preview Locally

Because the project uses standard web technologies without external build tools, you can preview it in several easy ways:

### Option 1: Directly Open in Browser
Double-click `index.html` or drag it into any web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Using Python's Built-in Server
Open your terminal inside this folder and run:
```bash
python -m http.server 8000
```
Then visit [http://localhost:8000](http://localhost:8000) in your browser.

### Option 3: VS Code Live Server
If you use VS Code, right-click `index.html` and select **"Open with Live Server"**.

---

## ✏️ Customization Checklist

Here are the key places to personalize:

1. **Email & Socials:**
   - In `index.html`, replace all instances of `your.email@example.com` with your real email.
   - Update the LinkedIn URL in the Hero, Contact, and Footer sections (`https://www.linkedin.com/in/yourprofile`).
2. **Resume:**
   - Place your resume PDF in `assets/resume.pdf`.
   - Update the resume button `href` in `index.html` to point to `assets/resume.pdf`.
3. **Profile Avatar:**
   - Place an image (e.g. `assets/profile.jpg`) and replace the initials placeholder in the `.avatar-frame` section of `index.html`.
4. **Projects:**
   - Update the project titles, descriptions, and tag pills in the `#projects` section.
   - Replace project links with your actual GitHub repository URLs and live deployment links.
5. **Experience & Education:**
   - Update school name, graduation date, coursework, and work experience in the `#experience` section.

---

## 🚢 Publishing to GitHub Pages

Since your repository is named `isaiahvk.github.io`, GitHub automatically deploys the `main` branch to your root domain!

To push your changes:

```bash
git add .
git commit -m "Launch new personal portfolio site shell"
git push origin main
```

Your live site will be updated at **https://isaiahvk.github.io/** within 1–2 minutes!
