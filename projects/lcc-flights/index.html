Low-Cost Carrier Flight Opportunities

Spirit Airlines filed for bankruptcy twice in a year and has since stopped flying. Ultra-low-cost carriers (ULCCs) live or die by picking the right nonstop routes. This project uses Bureau of Transportation Statistics itinerary data to find out which routes could keep that business model alive.

Model 1's high R² comes mostly from existing demand: passengers and revenue correlate at 0.94. Without that feature (Model 2), weather, distance and region explain far less, which is why Model 3 uses a random forest to capture non-linear effects and avoid negative predictions.

06 · LIMITATIONS

What the models can't see

  • Revenue isn't profit. Fleet, hub location and cost structure differ by airline, so a route that pays off for one carrier can lose money for another.
  • Linear models don't know the valid range. Model 2 predicts −16 passengers for ALB→MSY, which is impossible.
  • The temperature input is a proxy. Training used a latitude-based temperature estimate to stay under API rate limits. Real Open-Meteo data is used only at prediction time.
  • The data is a 10% sample. BTS DB1B publishes a 10% ticket sample, so absolute passenger and revenue numbers are understated.
